# Airline Reservation System

A console-based Airline Reservation System developed in C++. This project demonstrates the implementation of Object-Oriented Programming (OOP) concepts such as classes, inheritance, polymorphism, and encapsulation, along with file handling for permanent data storage.

## Features
- Add Flight Reservations
- View Booking Details
- Update Reservations
- Cancel Reservations
- Search Flights
- Save and Load Data using Files
- Menu-Driven Interface

## Technologies Used
- C++
- OOP Concepts
- File Handling

This project was developed for learning and practicing C++ programming, data management, and software design principles.
